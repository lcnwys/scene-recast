# Security policy

## Supported versions

Security reports are accepted for the latest version on the default branch.

## Report a vulnerability

Please do not report security issues in public issues. Use GitHub's private vulnerability reporting for this repository. Include steps to reproduce and the impact. Do not attach API keys, private videos, audio, or transcripts.

This app is designed for local use and binds to `127.0.0.1`. Do not expose it to a network or deploy it as a public service.
